# Security policy

Report vulnerabilities through GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Scope: the Protocol definitions and verification helpers in this repository:

- `avr/1` Receipts, signatures and Raw Capture encryption
- `veriprov/1` binding, HPKE sealing and envelope signatures
- The Guest Manifest and Bootstrap schemas and validators

Each consumer (VeriRelay, VeriProv, VeriForge, Verifier) covers its own vulnerabilities in its own repository.
